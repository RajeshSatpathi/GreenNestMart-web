Project: Organic E-Commerce Website (Vendor & Admin Panel)

Developed a full-stack organic e-commerce web application that enables users to browse and purchase organic products while providing dedicated vendor and admin dashboards for efficient product and order management.

🔹 Key Features

•	Built a responsive and user-friendly frontend using React JS, HTML5, CSS3, and JavaScript (ES6+)

•	Implemented component-based architecture with React functional components and hooks

•	Developed vendor panel for product listing, inventory management, and order tracking

•	Created admin dashboard to manage users, vendors, products, and orders

•	Integrated REST APIs for dynamic data handling between frontend and backend

•	Implemented state management for cart, authentication, and product data

•	Ensured responsive design for mobile, tablet, and desktop devices

•	 Payment options: Cash on Delivery + Stripe (test mode)



🔹 Learning & Technical Highlights

•	Applied clean and reusable code practices

•	Gained experience in API integration, CRUD operations, and role-based access

•	Used Git & GitHub for version control and project collaboration

•	Focused on performance optimization and smooth user experience

•	Strengthened understanding of full stack development fundamentals

🔹 Challenges & Learnings:

One of the major challenges was managing global state for cart and user authentication.
I solved this using Redux Toolkit, which helped structure the state efficiently and improved overall performance.
This project helped me strengthen my understanding of full-stack development, API design, state management, and real-world e-commerce workflows.

🔹 Tech Stack

Frontend: React JS, JavaScript (ES6+), HTML5, CSS3, tailwind CSS , Redux Toolkit

Backend: REST APIs (Backend fundamentals) Node js , express js , MongoDB for Database

Tools: JWT, Cloudinary , CORS , Multer , bcrypt , figma UI design , responsive design
